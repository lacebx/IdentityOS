# IdentityOS Chrome Extension

Bridges ChatGPT and other web apps with the IdentityOS runtime.

## Setup

1. Open `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this directory
4. Ensure the IdentityOS runtime is running on `localhost:8000`

The extension injects identity context into supported web apps, enabling cross-app memory.
