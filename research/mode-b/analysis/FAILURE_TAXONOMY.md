# Cross-model failure taxonomy

This file will be populated from initial bare and IDOS runs across the first three-model sample.

Planned cross-model categories:

- reasoning
- memory / profile recall
- persistence
- tool intent / execution
- tool result authority
- long-task / multi-step
- truthfulness / hallucination
- latency / practicality

The goal is to distinguish:

- model capability limits
- runtime limitations
- model-specific regressions
- failures consistently improved by IdentityOS
