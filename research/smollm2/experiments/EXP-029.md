# Experiment EXP-029

**Status:** REVERT
**Date:** 2026-08-24 (early AM run)

## Hypothesis

Adding a system prompt instruction asking the model to verify its work should reduce
reasoning and long-task failures (E01, E02, E03) without hurting tool-use or truthfulness.

## Bottleneck

Long-task (E01/E02/E03) and tool (C01/C02) failures dominate the remaining 7 failing tasks.
Specifically, multi-step arithmetic errors in E01 and ordered recall errors in E02/E03.

## Change

`adapters/openai_adapter.py` — `OllamaAdapter._build_messages`: prepended a verification
directive to the system prompt instructing the model to double-check calculations and facts
before responding.

## Expected mechanism

A self-verification instruction nudges the model to allocate more "reasoning tokens" before
answering, reducing arithmetic slips and ordering errors.

## Failure analysis

The verification directive unexpectedly disrupted tool-use formatting. The system prompt
addition consumed tokens and context that the model was using to track tool-call format.
The tools category dropped substantially (strongly suspected: the verify prefix caused
the model to emit prose reasoning instead of JSON tool calls).

Confidence in diagnosis: **strongly suspected** (not confirmed; no per-task breakdown
in this artifact).

## KEEP / REVERT

**REVERT** — 7-task regression; success gate and category gate both failed.
